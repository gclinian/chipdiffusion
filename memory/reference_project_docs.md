新 session 開始要讀的檔案，依序：

1. `CLAUDE.md`（project root）— 規則、checkpoint 路徑、eval command 範本、gotchas
2. `docs/context.txt` — cross-session hand-off（實驗歷史壓縮版、TO CONTINUE 指令）
3. `docs/plan/*` — 所有實驗計畫（含判定標準）
4. `docs/report/*` — 所有實驗結果
5. `docs/next/*` — 每次實驗後的反思與下次方向
6. `docs/meet/*` — 教授會議紀錄（重要建議來源）

**How to apply:** 一開新 session 先讀 1 + 2，再按需要讀對應的 plan/report。使用者會明確告訴你卡在哪個實驗、要繼續做什麼。
