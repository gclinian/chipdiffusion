# Meeting Notes — 2026/06/20

## 教授建議

### 1. Data augmentation 試試看
在現有 synthetic dataset 上做 augmentation（旋轉/鏡射/縮放等 placement-invariant 變換），看能否提升 zero-shot transfer。

### 2. 嘗試新的 model 架構：Flow Matching、Drifting Model
跳出 DDPM 框架。Flow matching (Lipman et al. 2023) 用 ODE 直線路徑取代 stochastic reverse；drifting model 系列是更新的 few-step 生成範式。可能 (a) 品質更好、(b) inference 快 10-100×、(c) 跟 guidance 結合方式不同。

### 3. ISPD2005 的極限是什麼？
目前所有方法擠在 44-47 區間（paper 46.89 → 我們最佳 44.01，只差 6%）。可能 ISPD2005 macro-only 的 achievable HPWL 下限就在 ~43-44 附近，方法再好也擠不出改善。需要估計 lower bound；若已到極限 → 換 dataset（IBM/ICCAD04、更新 benchmark）才能看出方法差異。

### 4. 傳統 EDA 方法生的 dataset 拿來用用看
目前訓練資料全是 synthetic（隨機生成 + inverse problem 保證 near-optimal）。改用傳統 EDA placer（DREAMPlace / SA-based）對真實或合成 netlist 產生的 placement 當訓練 label，distribution 更接近真實最佳解。
